# torment

打开VisualStudio创建一个程序
突然脑子短路用define做了一个程序
## 用法
- 输入一个数(非数字默认0)
- 输出累加和
### 例
- 输入：5
- 运算：5+4+3+2+1
- 输出：15
## 注
- 程序有BUG，觉得不舒服可以自行修复(前提你看得懂)
